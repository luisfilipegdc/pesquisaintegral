# Feedback Semi-Integral · 2º Semestre 2026 (4º e 5º ano)

Página animada com o resultado da pesquisa "Isso aqui tá bão demais" / "Pode miorá".

Site estático (HTML + CSS + JS, sem build). As respostas ficam em `script.js` (arrays `BAO` e `MIORA`).

## Publicar na Vercel
1. Em vercel.com → **Add New… → Project** → importe este repositório.
2. Framework Preset: **Other**. Sem comando de build, diretório de saída padrão.
3. **Deploy**.

Ou pela CLI: `npx vercel --prod`.
